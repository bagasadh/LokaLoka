# Lokaloka

Nearby food stall and restaurant finder using OpenStreetMap and the Overpass API (no API key required).

## Features
- Interactive map and location search for nearby food stalls.
- Stall pages with hours, menus, prices, and owner edit mode.
- User reviews with ratings, photos, and receipt proof.
- Mobile-first dark UI (`#202020`).

## Development

```sh
npm install
npm run dev
```

Build with `npm run build` and run tests with `npm test`.
