# Lokaloka

Aplikasi pencarian warung dan tempat makan di sekitar lokasi pengguna menggunakan OpenStreetMap dan Overpass API.

## Fitur Utama

- **Peta Interaktif**: Deteksi warung dan kuliner sekitar secara realtime (bebas API key, menggunakan OpenStreetMap + Overpass).
- **Pencarian Lokasi**: Cari tempat/alamat dan otomatis mendeteksi warung di radius area tersebut.
- **Profil & Menu Warung**: Menampilkan detail tempat, jam buka, daftar menu beserta harga.
- **Ulasan Terverifikasi**: Pengguna dapat memberikan ulasan, rating bintang, foto, serta bukti nota/struk pembelian.
- **Mode Pemilik**: Pengelolaan daftar menu dan harga langsung oleh pemilik warung.
- **Mobile First**: Dioptimalkan untuk perangkat layar handphone (5.4" - 6.9") dengan dark UI (#202020 & aksen putih).

## Development

Pastikan Node.js (v18+) dan npm sudah terpasang.

```sh
# Install dependensi
npm install

# Jalankan server development
npm run dev

# Jalankan test
npm test

# Build untuk produksi
npm run build
```
